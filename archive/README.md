# Archive

This folder holds what is no longer part of the game. Above all an earlier idea of the team, the betting app “We Be(a)t”, which we dropped in favour of the game “Group Project” (see S-01 and S-45 in [game/DECISIONS.md](../game/DECISIONS.md)). It is kept for the record and is not part of the deployed application.

- `prototype/`: the prototype, plain HTML, CSS and JavaScript ([prototype/README.md](prototype/README.md))
- `tests/`: its flow tests, run with `node archive/tests/run.js` from the main folder (the CI still runs them)
- [TODO.md](TODO.md), [DECISIONS.md](DECISIONS.md), [FEATURES.md](FEATURES.md): its lists, in German
- `game-docs/`: two working notes of area 3 of the game from 2026-11-20 (a play test and a table of rule tests), in German and out of date (fail range 5, report range 2, key Q). They were moved here from `game/docs/` on 2026-11-23 because everything in `game/` is in English and up to date; the current rules are in [game/DESIGN.md](../game/DESIGN.md) and the tests in `game/tests/`.

The game itself lives in [game/](../game/), described in the [README.md](../README.md) of the main folder.
