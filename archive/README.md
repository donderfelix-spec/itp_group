# Archive: “We Be(a)t”

This folder holds an earlier idea of the team, the betting app “We Be(a)t”, which we dropped in favour of the game “Group Project” (see S-01 and S-45 in [game/DECISIONS.md](../game/DECISIONS.md)). It is kept for the record and is not part of the deployed application.

- `prototype/`: the prototype, plain HTML, CSS and JavaScript ([prototype/README.md](prototype/README.md))
- `tests/`: its flow tests, run with `node archive/tests/run.js` from the main folder (the CI still runs them)
- [TODO.md](TODO.md), [DECISIONS.md](DECISIONS.md), [FEATURES.md](FEATURES.md): its lists, in German

The game itself lives in [game/](../game/), described in the [README.md](../README.md) of the main folder.
